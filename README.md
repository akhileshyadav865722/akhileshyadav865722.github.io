## 📌 Project Overview

This repository contains the source code for my **Personal Developer Portfolio**, hosted live via **GitHub Pages** at [**akhileshyadav865722.github.io**](https://akhileshyadav865722.github.io).

The website serves as a central hub showcasing my technical projects, core skills, educational background in Information Technology, and contact information for recruiters and collaborators.

## ✨ Features

- 🌟 **Hero Introduction**: Professional overview with quick navigation and resume access.
- 🛠️ **Skills & Technologies Matrix**: Highlighting core proficiencies in Full Stack development (Angular, React, .NET, Node.js, SQL, MongoDB).
- 🚀 **Featured Projects Section**: Interactive showcase cards linking directly to GitHub repositories and live deployments.
- 📱 **Fully Responsive Layout**: Designed to provide an optimal browsing experience on mobile, tablet, and widescreen monitors.
- 📬 **Contact Section**: Direct links to connect via LinkedIn, GitHub, and Email.

---

## 🛠️ Technologies Used

- **Markup**: HTML5
- **Styling**: CSS3 (Responsive Grid, Flexbox, Custom Shadows & Transitions)
- **Scripting**: Vanilla JavaScript (Interactive elements and smooth scrolling)
- **Hosting & Deployment**: GitHub Pages

## ⚙️ Running Locally

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/akhileshyadav865722/akhileshyadav865722.github.io.git
   cd akhileshyadav865722.github.io
   ```
2. **Open in Browser:**
   - Double-click `index.html` to view the website locally in any browser.
   - Or open using VS Code **Live Server** (`Alt + L, Alt + O`).
